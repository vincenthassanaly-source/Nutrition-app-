# Règles de workflow Git

- Après chaque modification terminée et fonctionnelle (code qui compile/passe les vérifications de base), commit et push automatiquement sur la branche par défaut du dépôt, sans attendre de validation explicite de l'utilisateur.
- Ne pas créer de pull request, sauf demande explicite de l'utilisateur.
- Ne pas demander l'accord de l'utilisateur avant de commit/push : ces actions sont pré-autorisées pour ce projet.
- Utiliser des messages de commit clairs et descriptifs.
